# Crédits des images de My memories

- Planches de stickers, frise de dentelles, collage rétro et collage vintage : images fournies par Louenn le 26/11/2026 (trouvées sur Pinterest), découpées pour l'appli. Signature gardée sur le champignon fantôme (Fairydrop art).
- Pièces retenues dans le collage vintage : timbres (Klimt, Brésil, chats), frises (souris, pommes), carreau, tapis, mosaïque, ange paon, azulejo, vitraux, nénuphars. Les pièces politiques ou religieuses du collage n'ont pas été utilisées.
